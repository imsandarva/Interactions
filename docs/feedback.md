# Feedback

Study 02. A quiet invitation.

The home row reads Feedback. Inside, the page offers one honest note, and a single button reads Give us feedback.

Tapping the button presses, and that is all for now. Bad, Fine, and Great are not on this screen yet. The tap is held in `lib/studies/feedback/feedback_screen.dart`, so the prompt can be attached there later without moving the layout.

The words live in `lib/studies/feedback/copy/feedback_copy.dart`.
